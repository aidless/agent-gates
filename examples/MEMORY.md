# 示例记忆索引（假数据，只用于让示例跑通）

## 备份与截断
整份写回会在中途出错时把文件截成 0 字节，所以追加型文件一律用单次追加写：先把正文算完整，再开写模式，写完立刻复验前缀一致性和正文哈希。这是本项目最贵的一次事故，代价是三天的历史记录全部丢失，最后只能从三天前那份语义命名的备份里把段标题逐条对回来的。

## 锁与并发
多会话同时追加要拿排他锁。锁只包住追加这一小段，持锁期间不执行长命令，否则别的会话会被一起卡住还可能切断别人正在跑的回合，而持锁跑长命令正是上一节课被点名批评过的那一类错误，代价是四个并行会话同时被打断且恢复后不会自动续跑。

## 检索上限
纯词频检索在换说法时召回不足，同一件事换个说法就搜不到，于是记录过的教训等于没记。这是词袋模型的天花板，不是语料没写清楚；只有把检索换成向量检索才有机会变好，而在此之前应当把这些检索能力上限登记成已知失败，让它们不阻断、但也不冒充通过。
